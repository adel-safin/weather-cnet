# Погода

Один экран с погодой в Москве: сейчас, по часам (остаток сегодняшнего дня и весь завтрашний) и прогноз на три дня. Данные с [weatherapi.com](https://www.weatherapi.com/).

## Как запустить

Ключ из задания уже прописан, отдельно ничего настраивать не нужно.

```bash
docker compose up --build
```

Приложение будет на [http://localhost:8080](http://localhost:8080).

Локально без Docker:

```bash
dotnet run --project src/Weather.Web
```

Откроется [http://localhost:5187](http://localhost:5187), документация API - [http://localhost:5187/scalar/v1](http://localhost:5187/scalar/v1).

Свой ключ можно передать так, файлы трогать не обязательно:

```bash
WEATHER_API_KEY=ваш_ключ docker compose up --build
```

Тесты: `dotnet test`.

## Что внутри

Blazor Web App и Minimal API в одном хосте на .NET 10. Слои обычные: Domain, Application, Infrastructure, Web. UI и `/api/weather/dashboard` ходят в один и тот же запрос MediatR: оба эндпоинта провайдера вызываются параллельно, экран собирается одним ответом.

Почасовое окно считается в домене по локальному времени Москвы, а не по часам сервера. Ошибки провайдера - это `Result`, а не исключения: от кода ошибки в одном месте выбирается HTTP-статус и текст для пользователя. На время и лимит ключа стоят стандартный resilience-handler и кэш.

Подробности развилок - в [docs/adr](docs/adr).

## Отступления от текста задания

HTTPS вместо `http://` в примерах: ключ нельзя светить в открытом канале. Добавлен `lang=ru`, чтобы описания погоды были на русском. Координаты с клиента не принимаются - в задании локация фиксированная, иначе чужим ключом можно было бы ходить по всему миру. Ключ лежит в `appsettings.json`, чтобы проект поднимался одной командой; в проде его лучше вынести в переменную `Weather__WeatherApi__ApiKey`.

## Конфигурация

Имеет смысл трогать только ключ и, при необходимости, координаты. Остальное - таймауты, кэш и число повторов - уже выставлено.

| Ключ | Зачем |
| --- | --- |
| `Weather:WeatherApi:ApiKey` | доступ к провайдеру |
| `Weather:DefaultLocation:*` | город и координаты |
| `Weather:UseHttpsRedirection` | в Docker выключен: TLS снаружи |

Переменные окружения - через `__`, например `Weather__WeatherApi__ApiKey`.
